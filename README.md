Import **woofcash/yard** (not this profile repo):

1. Open [vercel.com/new](https://vercel.com/new)
2. Import Git Repository → `woofcash/yard`
3. Framework: Vite · Build: `npm run build` · Install: `npm install`
4. Deploy
5. After it is live, add `woofcash.xyz` in Project → Domains, then paste the A / CNAME records into Namecheap Advanced DNS
